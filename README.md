# CMM MAX

Сайт экосистемы приложений CMM MAX (Music Max + ERP Max).

Скачивание установщиков ведёт на Google Drive.

## Локальный просмотр

Откройте `index.html` в браузере или:

```bash
npx --yes serve -l 8787
```

## GitHub Pages

1. Создайте репозиторий на GitHub (например `cmm-max`).
2. Загрузите содержимое этой папки.
3. Settings → Pages → Source: Deploy from a branch → `main` / root.
4. Сайт будет по адресу: `https://ВАШ_ЛОГИН.github.io/cmm-max/`

Если репозиторий называется `ВАШ_ЛОГИН.github.io`, сайт откроется сразу на корневом домене.
